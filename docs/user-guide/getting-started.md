# Getting Started with RostraCore

Welcome to RostraCore - the comprehensive security guard management platform designed for South African security companies.

## System Requirements

### Browser Support
- Google Chrome (recommended)
- Microsoft Edge
- Mozilla Firefox
- Safari (macOS)

### Recommended Screen Resolution
- Minimum: 1280 x 720
- Recommended: 1920 x 1080 or higher

## Accessing the System

### Login
1. Navigate to your organization's RostraCore URL
2. Enter your **username** and **password**
3. Click **Sign In**

### First-Time Login
If this is your first time logging in:
1. Use the credentials provided by your administrator
2. You may be prompted to change your password
3. Complete your profile information

## Dashboard Overview

After logging in, you'll see the main dashboard with:

### Quick Stats
- **Total Employees**: Active guards in your organization
- **Active Sites**: Guard posts currently staffed
- **Upcoming Shifts**: Shifts scheduled for the current week
- **Payroll Status**: Current pay period summary

### Navigation Sidebar
The sidebar provides access to all main features:

| Menu Item | Description |
|-----------|-------------|
| Dashboard | Overview and quick stats |
| Employees | Manage guards and staff |
| Clients | Municipality and client management |
| Sites | Guard post locations |
| Shifts | Shift scheduling |
| Roster | Automated roster generation |
| Payroll | Payroll processing |
| Settings | Organization settings |

## Key Features Overview

### Employee Management
- Add and manage security guards
- Track PSIRA certifications
- Monitor certification expiry dates
- Manage availability schedules

### Client & Site Management
- Create client profiles (municipalities)
- Define guard post locations
- Set site requirements (armed/unarmed, PSIRA grades)
- Configure site-specific rates

### Roster Generation
- Automated shift assignment using AI optimization
- BCEA compliance (48 hours/week limit)
- PSIRA grade matching
- Night shift and weekend premium calculations

### Payroll Processing
- Automatic hour calculations
- SA tax calculations (PAYE, UIF)
- Premium pay for night/weekend shifts
- Payslip generation

## Getting Help

### In-App Support
- Click the **?** icon in the top-right corner for contextual help
- Check the notification bell for system alerts

### Contact Support
If you encounter issues:
1. Contact your organization administrator
2. Email support with:
   - Your organization name
   - Description of the issue
   - Screenshots if applicable
