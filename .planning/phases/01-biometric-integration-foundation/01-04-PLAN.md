**Create `backend/app/api/endpoints/biometric.py`:**

Follow existing endpoint patterns (see employees.py): `router = APIRouter()`, use `Depends(get_db)`, `Depends(get_current_user)`, multi-tenancy via org_id.

Endpoints:
1. `POST /enroll/start` - Start enrollment session
   - Body: EnrollmentSessionCreate
   - Auth: Requires current_user with ADMIN or HR role (check current_user.role)
   - Calls start_enrollment_session()
   - Returns: EnrollmentSessionResponse

2. `POST /enroll/{session_id}/face` - Upload face image for enrollment
   - Accepts: `UploadFile` (the face image)
   - Auth: ADMIN or HR role only
   - Reads file bytes: `image_bytes = await file.read()`
   - Calls enroll_face(session_id, image_bytes, db)
   - Returns: EnrollmentResultResponse

3. `GET /enrollment-status/{employee_id}` - Check enrollment status
   - Auth: Any authenticated user (but only within same org)
   - Calls get_enrollment_status(employee_id, db)
   - Returns: EnrollmentStatusResponse

**Create `backend/app/api/endpoints/attendance.py`:**

Endpoints:
1. `POST /clock-in` - Multi-modal clock-in
   - Body: ClockInRequest (JSON) + Optional[UploadFile] for biometric image
   - Auth: Any authenticated user (employee self-service)
   - Logic:
     a. Get employee_id from current_user (lookup employee by user's email/id)
     b. If method is biometric_face: require file upload, extract embedding with DeepFace, call process_verification()
     c. If method is gps_only: validate geofence if site_id provided
     d. If method is manual_hr_approved: require ADMIN/HR role
     e. Create AttendanceRecord with all data
     f. If requires_hr_review: flag the record
   - Returns: ClockInResponse

2. `POST /clock-out/{record_id}` - Clock out from attendance
   - Body: ClockOutRequest (optional GPS)
   - Updates AttendanceRecord.clock_out_at
   - Returns: AttendanceRecordResponse

3. `GET /records` - List attendance records (paginated)
   - Query params: employee_id (optional), site_id (optional), date_from (optional), date_to (optional), requires_review (optional bool), page (default 1), per_page (default 50)
   - Auth: ADMIN/HR see all org records, employees see only their own
   - Filter by org_id (multi-tenancy)
   - Join Employee for employee_name, Site for site_name
   - Returns: `{"items": list[AttendanceRecordResponse], "total": int, "page": int, "per_page": int}`

4. `GET /hr-review` - List records pending HR review
   - Filter: requires_hr_review=True AND hr_reviewed_by IS NULL
   - Auth: ADMIN/HR only
   - Returns: list[AttendanceRecordResponse]

5. `POST /{record_id}/review` - HR reviews flagged attendance
   - Body: AttendanceReviewRequest
   - Auth: ADMIN/HR only
   - If approved: set requires_hr_review=False, record reviewer
   - If rejected: mark record (keep for audit trail, don't delete)
   - Returns: AttendanceRecordResponse

- Validate that referenced site_id belongs to the same org
