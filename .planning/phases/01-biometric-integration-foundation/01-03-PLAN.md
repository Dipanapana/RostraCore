**encryption.py - Template encryption/decryption using pgcrypto:**

```python
# backend/app/biometric/encryption.py
"""Biometric template encryption using PostgreSQL pgcrypto."""

from sqlalchemy import text
from sqlalchemy.orm import Session
import json
import os

def get_encryption_key() -> str:
    """Get biometric encryption key from environment."""
    key = os.getenv("BIOMETRIC_ENCRYPTION_KEY")
    if not key:
        raise RuntimeError("BIOMETRIC_ENCRYPTION_KEY environment variable not set")
    return key

def encrypt_template(db: Session, embedding: list[float]) -> bytes:
    """
    Encrypt a biometric embedding using pgcrypto.

    Args:
        db: SQLAlchemy session (for pgcrypto SQL call)
        embedding: List of floats (e.g., 512-d face vector)

    Returns:
        Encrypted bytes ready for storage in BYTEA column
    """
    key = get_encryption_key()
    embedding_json = json.dumps(embedding)
    result = db.execute(
        text("SELECT pgp_sym_encrypt(:data, :key, 'cipher-algo=aes256')"),
        {"data": embedding_json, "key": key}
    )
    return result.scalar()

def decrypt_template(db: Session, encrypted_data: bytes) -> list[float]:
    """
    Decrypt a biometric embedding from pgcrypto-encrypted storage.

    Args:
        db: SQLAlchemy session
        encrypted_data: BYTEA from biometric_templates.encrypted_template

    Returns:
        List of floats (the original embedding)
    """
    key = get_encryption_key()
    result = db.execute(
        text("SELECT pgp_sym_decrypt(:data, :key)"),
        {"data": encrypted_data, "key": key}
    )
    decrypted_json = result.scalar()
    return json.loads(decrypted_json)
```

**liveness.py - Passive liveness detection:**

Create `backend/app/biometric/liveness.py` with passive liveness checks. This analyzes the image (NOT the embedding) for signs it's a real face vs printed photo or screen:

```python
def check_liveness(image_bytes: bytes) -> dict:
    """
    Passive liveness detection on enrollment/verification image.

    Checks:
    1. Face detected by DeepFace (retinaface backend for quality)
    2. Image sharpness (Laplacian variance) - detects printed photos
    3. Brightness distribution - detects screen displays

    Returns:
        {
            "is_live": bool,
            "face_detected": bool,
            "sharpness_score": float,
            "brightness_ok": bool,
            "face_confidence": float,
            "issues": list[str]  # Human-readable issues
        }
    """
```

Implementation approach:
- Use DeepFace.extract_faces() with detector_backend="retinaface" to detect face and get confidence
- Convert image bytes to numpy array using cv2.imdecode (opencv-python comes with deepface)
- Calculate Laplacian variance for sharpness: `cv2.Laplacian(gray, cv2.CV_64F).var()` - threshold at 100
- Calculate mean brightness of face region - reject if < 60 (too dark) or > 220 (overexposed/screen glare)
- Return is_live=True only if face_detected AND sharpness > 100 AND brightness in range
- Return issues list with specific guidance: "Image too blurry - hold device steady", "Too dark - need more light", "No face detected - position face in frame"

Do NOT implement active liveness (blink/head turn) - per research, passive is sufficient for Phase 1, active deferred to Phase 2 if fraud detected.
