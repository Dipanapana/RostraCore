## Decisions Made

**1. Use useSyncExternalStore for network detection**
- Rationale: React 18+ standard for subscribing to external data sources (window.navigator.onLine), proper SSR handling

**2. Add isTauri() check to localDb client**
- Rationale: Enables hooks to work in web browser for testing/development without crashing when Tauri APIs unavailable

**3. Parse data_json field when loading from cache**
- Rationale: SQLite stores full API response as JSON string in data_json column, needs parsing to return same structure as API

**4. Log '[Offline]' messages to console**
- Rationale: Helps developers and users understand when app is using cached data vs live API
