## Decisions Made

**1. Banner hidden when online and idle with no errors**
- Rationale: Avoids visual clutter when connection is normal. Only shows banner when user needs to know about offline/sync state.

**2. Amber banner for offline, blue for syncing, red for errors**
- Rationale: Color-coded status provides instant visual feedback. Amber = warning (offline but working), blue = info (syncing), red = error (action needed).

**3. Disable Add Employee and Import buttons when offline (not all features)**
- Rationale: These are write operations requiring API. Employee list remains viewable (uses cached data). Selective disabling better than blocking entire page.

**4. Payroll page fully blocked offline (write-only workflow)**
- Rationale: Payroll processing requires server-side calculations (PAYE, UIF, SDL). No value in showing cached payroll records offline.

**5. Employee list remains viewable offline (uses cached data)**
- Rationale: Leverages offline-first hooks from plan 00.1-03. Users can view employees even offline, just can't add/edit.
