## Decisions Made

**1. Install @tauri-apps/api for Tauri invoke() function**
- Rationale: Required to call Tauri commands from frontend. Official API package for Tauri 2.0.

**2. Use useSyncExternalStore for sync status subscription**
- Rationale: React 18+ built-in hook for subscribing to external stores. Cleaner than useState + useEffect pattern.

**3. 5-minute auto-sync interval as default**
- Rationale: Balance between timely sync and avoiding excessive network requests. Configurable via startAutoSync parameter.

**4. Queue mutations when offline, call API directly when online**
- Rationale: Reduces latency when online (no queue overhead), enables offline work with later sync.

**5. Optimistic updates with context-based rollback**
- Rationale: Better UX (instant feedback), with automatic revert if API fails. Standard React Query pattern.
