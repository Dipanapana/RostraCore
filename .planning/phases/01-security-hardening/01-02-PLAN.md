<task type="auto">
  <name>Task 1: Enforce four-class password policy in password_validator.py</name>
  <files>backend/app/auth/password_validator.py</files>
  <action>
    The current validator only checks minimum length (8 chars from config). It must also require:
    - At least one uppercase letter (A-Z)
    - At least one lowercase letter (a-z)
    - At least one digit (0-9)
    - At least one special character from the set: !@#$%^&*()_+-=[]{}|;':,./<>?

    Implementation:

    1. Add `import re` at the top of the file.

    2. Replace the body of `validate_password_strength` with:
       ```python
       min_length = settings.PASSWORD_MIN_LENGTH

       if len(password) < min_length:
           return False, f"Password must be at least {min_length} characters long"

       if not re.search(r'[A-Z]', password):
           return False, "Password must contain at least one uppercase letter"

       if not re.search(r'[a-z]', password):
           return False, "Password must contain at least one lowercase letter"

       if not re.search(r'\d', password):
           return False, "Password must contain at least one number"

       if not re.search(r'[!@#$%^&*()\-_=+\[\]{}|;:\'",.<>/?\\`~]', password):
           return False, "Password must contain at least one special character (e.g. !@#$%^&*)"

       return True, "Password meets all requirements"
       ```

    3. Update `get_password_requirements()` to return the full requirements:
       ```python
       return {
           "min_length": settings.PASSWORD_MIN_LENGTH,
           "requires_uppercase": True,
           "requires_lowercase": True,
           "requires_number": True,
           "requires_special_character": True,
           "description": (
               f"Password must be at least {settings.PASSWORD_MIN_LENGTH} characters "
               "and contain uppercase, lowercase, a number, and a special character"
           )
       }
       ```

    This change automatically propagates to /register and /reset-password in auth.py since they both call `validate_password_strength`.

    Do NOT change PASSWORD_MIN_LENGTH in config.py — the existing value (8) is fine.
  </action>
  <verify>
    Test the validator directly:
    ```

    assert not ok, f'Expected failure, got: {msg}'
    print(f'Correctly rejected: {msg}')

    # Should pass
    ok, msg = validate_password_strength('Password1!')
    assert ok, f'Expected success, got: {msg}'

    print('All password tests passed')
    "
    ```
    Expected: All three assertions pass and prints "All password tests passed".
