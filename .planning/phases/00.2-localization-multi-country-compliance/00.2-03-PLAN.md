    - R20,000/month -> capped at R17,712 -> employee UIF = R177.12

    **SA SDL Tests:**
    - Payroll below R500k/year -> SDL = R0
    - Payroll above R500k/year -> SDL = 1% of monthly payroll

    - $30,000/year -> 10% bracket + partial 12% bracket

    - GBP 12,570/year -> zero tax (personal allowance)
    - GBP 30,000/year -> basic rate on amount above allowance
    - GBP 60,000/year -> higher rate bracket
    - NI: 8% on earnings above GBP 12,570 (up to GBP 50,270), 2% above

    - ZA: R25,000 gross -> verify PAYE + UIF = correct total deductions, net = gross - deductions
    - US: $5,000/month -> verify Federal tax + FICA = correct, net correct
    - GB: GBP 3,000/month -> verify PAYE + NI = correct, net correct

    **Labor Law Engine:**

    The LaborLawEngine class takes a country config dict and validates:
    1. Maximum weekly hours (with country-specific limits)
    2. Maximum daily hours
    3. Minimum rest between shifts
    4. Maximum consecutive working days
    5. Meal break requirements
    6. Overtime classification
    7. Violation severity (block/warn/info from config)

    Test cases (RED phase):

    **SA Labor Law Tests:**
    - Shift worker: 48h max weekly -> 50h triggers block
    - Office worker: 45h max weekly -> 46h triggers block
    - 11h rest between shifts -> triggers block (min 12h)
    - 7 consecutive days -> triggers warn (max 6)
    - 6h shift without meal break -> triggers warn
    - Is overtime: 49h in week (shift worker) -> True

    **US Labor Law Tests (FLSA):**
    - 40h max weekly -> 41h triggers overtime (info, not block)
    - No federal meal break requirement -> no violation for 8h shift
    - Overtime multiplier = 1.5x after 40h

    **UK Labor Law Tests (Working Time Directive):**
    - 48h max weekly (with opt-out) -> configurable
    - 11h rest between shifts
    - 28 days annual leave
    - Max 6 consecutive days

    **Severity Tests:**
    - SA max_weekly = "block" severity -> validate_shift returns violation
    - SA max_consecutive = "warn" severity -> validate_shift returns warning
    - SA overtime = "info" severity -> validate_shift returns info
