## Decisions Made

1. **Country config as JSON files** - Enables adding new countries without code changes (just upload JSON)
2. **Origin-country locale for currency formatting** - ZAR always displays as "R 1 234,56" (SA format), not user's locale
3. **Numeric(12,2) for monetary amounts** - Prevents floating-point rounding errors in payroll calculations
4. **Server default values for migration** - Existing orgs default to ZA/ZAR for backward compatibility
5. **CountryService as class with @classmethod** - Matches existing service pattern (sa_payroll_service.py)
6. **Intl.NumberFormat over third-party libraries** - Native browser API, no dependencies, handles all locales
