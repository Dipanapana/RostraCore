The `get_revenue_cost_comparison` endpoint currently loads all assignments with one query, then inside a `for assignment in assignments` loop makes individual `db.query(Shift)`, `db.query(Site)`, and `db.query(Client)` calls per assignment. With N assignments that is 3N extra queries.

Replace with a single joined bulk query using `joinedload` or an explicit JOIN. The `assignments` variable already joins Shift; extend that join to include Site and Client, then access the related objects via relationship attributes on the already-loaded ORM objects:

```python
from sqlalchemy.orm import joinedload

assignments = db.query(ShiftAssignment).join(
    Shift, Shift.shift_id == ShiftAssignment.shift_id
).join(
    Site, Site.site_id == Shift.site_id
).outerjoin(
    Client, Client.client_id == Site.client_id
).options(
    joinedload(ShiftAssignment.shift).joinedload(Shift.site).joinedload(Site.client)
).filter(
    and_(
        Shift.org_id == org_id,
        Shift.start_time >= datetime.combine(period_start, datetime.min.time()),
        Shift.end_time <= datetime.combine(period_end, datetime.max.time()),
        ShiftAssignment.status.in_(["confirmed", "completed"])
    )
).all()
```

Then in both the `group_by == "client"` branch and the `else` (time period) branch, replace the inner per-assignment queries with direct attribute access:

```python
for assignment in assignments:
    shift = assignment.shift           # already loaded via joinedload

    client_name = client.client_name if client else "Unknown"

    hours = assignment.regular_hours + assignment.overtime_hours
    # ... rest of grouping logic unchanged
```

No more individual `db.query(Shift)`, `db.query(Site)`, or `db.query(Client)` calls inside the loop. Remove those three lines from both branches.

Also ensure `joinedload` is imported from `sqlalchemy.orm` (add to existing import if not present).

Verify that `Shift.site` relationship exists (it does — `site = relationship("Site", back_populates="shifts")`), and `Site.client` relationship exists (it does — `client = relationship("Client", back_populates="sites")`).

**Fix the /confirm endpoint in roster.py** to create a `Roster` record before (or during) confirming assignments.

The current endpoint calls `ShiftService.assign_employee()` for each assignment but never creates a Roster. Fix:

1. **Add Roster import** at the top of roster.py:
   ```python
   from app.models.roster import Roster
   ```

2. **Inside `confirm_roster`**, before the assignment loop, collect the shift IDs from the incoming assignments list to determine the date range and create a Roster record:

   ```python
   import uuid

   # Collect shift IDs to determine date range
   shift_ids_to_confirm = [a["shift_id"] for a in assignments]
   shifts_for_range = db.query(Shift).filter(
       Shift.shift_id.in_(shift_ids_to_confirm)
   ).all()

   if shifts_for_range:
       roster_start = min(s.start_time for s in shifts_for_range)
       roster_end = max(s.end_time for s in shifts_for_range)
   else:
       roster_start = datetime.utcnow()
       roster_end = datetime.utcnow()

   # Generate a unique roster code
   roster_code = f"R{roster_start.strftime('%Y-%m')}-{uuid.uuid4().hex[:6].upper()}"

   # Create the Roster record
   roster = Roster(
       org_id=current_user.org_id,
       roster_code=roster_code,
       name=f"Roster {roster_start.strftime('%d %b %Y')} – {roster_end.strftime('%d %b %Y')}",
       start_date=roster_start,
       end_date=roster_end,
       status="draft",
       total_shifts=len(set(shift_ids_to_confirm)),
       assigned_shifts=0,
       unassigned_shifts=0,
       total_cost=0.0,
       created_by=current_user.user_id,
   )
   db.add(roster)
   db.flush()  # flush to get roster.roster_id before loop
   ```

3. **In the assignment loop**, after `ShiftService.assign_employee()` succeeds, also create/update the ShiftAssignment's roster_id. The `ShiftService.assign_employee()` returns a `Shift` object. After getting the shift, find or create the ShiftAssignment for that shift+employee and set its `roster_id`:

   ```python
   for assignment in assignments:
       shift = ShiftService.assign_employee(
           db,
           assignment["shift_id"],
           assignment["employee_id"]
       )
       if shift:
           confirmed_count += 1
           shift_ids.append(shift.shift_id)

           # Link the ShiftAssignment to the Roster
           from app.models.shift_assignment import ShiftAssignment
           sa = db.query(ShiftAssignment).filter(
               ShiftAssignment.shift_id == assignment["shift_id"],
               ShiftAssignment.employee_id == assignment["employee_id"]
           ).first()
           if sa:
               sa.roster_id = roster.roster_id
               sa.status = 'confirmed'
               sa.is_confirmed = True
               sa.confirmation_datetime = datetime.utcnow()
   ```

4. **Update the Roster stats** after the loop:
   ```python
   roster.assigned_shifts = confirmed_count
   roster.unassigned_shifts = len(assignments) - confirmed_count
   roster.total_cost = db.query(
       func.sum(ShiftAssignment.total_cost)
   ).filter(
       ShiftAssignment.roster_id == roster.roster_id
   ).scalar() or 0.0
   db.commit()
   ```

5. **Add `roster_id` to the response**:

   ```python
       "success": True,
       "confirmed_shifts": confirmed_count,
       "total_assignments": len(assignments),
       "roster_id": roster.roster_id,
       "roster_code": roster.roster_code,
   }
   ```

6. **Add missing imports** at the top of roster.py: `import uuid`, `from sqlalchemy import func`, `from app.models.shift_assignment import ShiftAssignment` (if not already imported), `from app.models.roster import Roster`.
